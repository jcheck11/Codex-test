# Art Asset Generation

This directory contains the GPT Image 2 asset prompts for the Codex Deckbuilder art pass.

The intended generated outputs are:

- `generated/table-background.png` — 16:9 gameplay table background.
- `generated/card-back.png` — vertical card back sprite source.
- `generated/modifier-badge.png` — passive modifier shop/UI icon.
- `generated/consumable-badge.png` — consumable shop/UI icon.

The prompts are stored in `prompts/gpt-image-2-assets.jsonl` and are written for the current GPT Image CLI default model, `gpt-image-2`.
